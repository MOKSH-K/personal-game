## 📖 About the Project

Family Game Night is a lightweight, browser-based project made with HTML, CSS, and JavaScript. It gives you a colorful place to choose from 30 games and can be used as a starting point for building a collection of family activities.

Game pages currently display a **“To Be Decided”** placeholder. Add your own game ideas and content to make the night yours!

## ✨ Features

- 30 numbered game cards
- Open a selected game in a new browser tab
- Distinct colors and simple card animations
- Responsive layout for desktop and mobile screens
- No frameworks, build tools, or dependencies required

## 🚀 Getting Started

### Run locally

1. Download or clone this repository.
2. Open `main.html` in your web browser.
3. Choose a numbered card to open its game page.

Alternatively, serve the project with a local static web server and open the local address it provides.

## 🎲 Customizing the Games

Game selection is handled in `main.html`. Update the `showPlaceholder()` function to replace the current placeholder with your own game instructions, questions, or activities.
